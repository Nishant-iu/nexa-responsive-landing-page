# Nexa — Responsive Landing Page

## About the Project
Nexa is a responsive landing page created as part of my Yuva Internship Week 1 task. The page presents a clean interface for a productivity platform.

## Features
- Responsive desktop and mobile layouts
- Navigation links to page sections
- Interactive mobile hamburger menu
- Hero section with a dashboard preview
- Features, About, Call-to-Action and Footer sections

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid and Media Queries)
- Vanilla JavaScript

## How to Run
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Resize the browser to test the responsive layout.

## Project Purpose
This project demonstrates the fundamentals of semantic HTML, responsive CSS, JavaScript interactivity and frontend development.
